# v0.3.7

## Features

- **mpv opts (#75):** launch with `--force-window=no` and `--speed` (default 1) so `mpv.conf` no longer leaks 2x playback or a video window for most users
- **Settings / `mpvExtraArgs`:** optional extra mpv CLI flags (quote-aware parsing; IPC-breaking flags denylisted)

## Notes

If you still need to ignore `mpv.conf` entirely, set Settings → mpv Extra Args to `--no-config`, or in `~/.youtube-music-cli/config.json`:

```json
"mpvExtraArgs": "--no-config"
```
